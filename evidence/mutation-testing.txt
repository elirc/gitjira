## Why this matters

Line coverage on fractional-index.js is ~100% (the property + example tests run
every line). Yet the MUTATION score is 80% — 17 mutants survived, meaning there
are code changes the tests do NOT detect. Coverage says "the line ran";
mutation testing says "the tests would notice if the line were wrong". Only the
second is what you actually want.
