# Self-audit — July 2026 (history as teaching material)

A blameless, honest audit of this repo's git history judged as **observational
learning material**. Committed on purpose (see WORKFLOW-IMPROVEMENTS §7): the point
is to diff the trajectory against future rounds and watch the workflow improve.

## What's genuinely strong (keep doing)

- **Commit granularity.** ~200 commits, no giant checkpoint feature commits; the
  largest non-merge/non-format commit is Prisma boilerplate. Real work lands small.
- **Test-first visible in history.** Red→green pairs, e.g. "prove the issue-key
  race (red)" → "allocate issue keys atomically (green)".
- **Rich commit bodies + ADRs + state snapshots.** The _why_ is visible almost
  everywhere. This is the strongest asset.
- **Conventional commits, consistent branch names, no-squash merges** preserving
  the granular history for study.

## What was wrong or misleading (fixed going forward)

1. **Reviews were single-author theater.** Every PR review was authored by one
   account. "Author", "Reviewer", "pentester" were the same person; planted bugs
   were self-caught. A legitimate teaching _device_, but not authentic review.
2. **Pre-commit hooks bypassed (`--no-verify`) ~throughout.** Consequence: ~21
   follow-up `style:`/`fix(lint)`/`ci:` commits fixing what a hook exists to catch,
   plus a multi-commit lockfile flail — i.e. CI discovered what local should have.
   This contradicted the "fail fast / local-prod parity" essays written in the same
   sprints.
3. **Some commit messages silently corrupted** — words dropped by a shell-escaping
   bug when piping messages containing backticks.
4. **Some features documented as done were never executed.** Perf numbers were
   real (measured); but E2E never ran green, images were never built,
   Lighthouse/NVDA/axe never ran, the "practice incident" and "~90s rollback" were
   narrated fiction. The PRs presented verified and unverified work with equal
   confidence.
5. **Compressed, unrealistic timeline** — six sprints in one sitting; no real CI
   waits, no review latency, no "slept on it".

## Skills that never appeared (added going forward)

Real debugging of a hard bug · a real incident + post-mortem · a real dependency
upgrade · profiling beyond the DB · load/stress testing · a real deploy+rollback ·
a11y verified with a real tool · observability used to find something · mutation
testing.

## Rating (honest)

- Code + commit craft + design reasoning as reference material: **~8/10**.
- Faithful model of how senior work actually happens end-to-end: **~5/10**
  (theatrical review, bypassed gates, unverified "done", no real
  debugging/incident/ambiguity).
- Blended, weighted to the upskilling goal: **~6.5/10**.

The corrective actions are in `WORKFLOW-IMPROVEMENTS.md`; this PR
(`chore/workflow-hardening`) is the first round that applies them.
