# GitJira

A Jira-style issue tracker, built in public as a teaching codebase.

This repository is a curriculum disguised as a product: it is being built across **15
sprints, each landing as a single pull request** full of educational artifacts — ordered
commits that tell a story, architecture decision records, `// LEARN:` teaching comments,
author self-reviews, and full review conversations. If you are a junior engineer, the way
to use this repo is to **read the pull requests in order**, follow the review threads, and
do the exercises in each sprint's learning brief.

> 🚧 Construction begins with PR #1. A proper quickstart README lands in Sprint 01.

## How to study this repo

1. Start at the oldest merged PR and read it commit by commit (not as one big diff).
2. Read the review conversation — the disagreements matter more than the approvals.
3. Each sprint ends with a pinned **Snapshot issue**: the state of the world, what to read,
   and checkpoint questions.
4. Do the exercises from `docs/sprints/` on your own branches.
